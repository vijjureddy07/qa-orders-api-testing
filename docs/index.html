API QUALITY ENGINEERING

Orders API Testing Lab

A local REST API and reproducible test suite for learning HTTP status codes, negative cases, lifecycle testing, SQL validation and CI.

01 / API

Five endpoints

Health, create, read, filter, and update order status.

02 / TESTS

Pytest + Postman

Functional, boundary, validation and state-transition checks.

03 / DATABASE

SQLite

Parameterized queries and API-to-database consistency checks.

Run it locally

python -m venv .venv
pip install -r requirements.txt
uvicorn app.main:app --reload
# Open http://localhost:8000/docs
pytest -v

The public GitHub Pages site contains documentation only. The API itself is not publicly hosted; run it locally or deploy to an authorized hosting service.

Educational local-service project — no customer data or external accounts.
